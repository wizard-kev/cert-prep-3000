# CCST Cybersecurity (100-160) Official Exam Topics

**Source:** Cisco Learning Network, "CCST Cybersecurity Exam Topics" (https://learningnetwork.cisco.com/s/ccst-cybersecurity-exam-topics), read 2026-10-07. Cisco states the topics "are subject to change at any time." Wording below is a condensed copy of Cisco's published topic list, kept as the basis for the Phase 7 crosswalk.
**Also on the page:** 50-minute exam; performance-based (lab-style) items are used, so "the number of questions on your exam may vary." No domain weights, question count, or passing score are published (see Scope section 3).
**Exam page:** https://www.cisco.com/site/us/en/learn/training-certifications/exams/ccst-cybersecurity.html (50 minutes, USD 125).

## 1.0 Essential Security Principles
- 1.1 Define essential security principles: vulnerabilities, threats, exploits, risks; attack vectors; hardening; defense-in-depth; CIA; types of attackers; reasons for attacks; code of ethics
- 1.2 Explain common threats and vulnerabilities: malware, ransomware, DoS, botnets, social engineering (tailgating, spear phishing, phishing, vishing, smishing), physical attacks, man in the middle, IoT vulnerabilities, insider threats, APT
- 1.3 Explain access management principles: AAA; RADIUS; MFA; password policies
- 1.4 Explain encryption methods and applications: types of encryption, hashing, certificates, PKI; strong vs weak algorithms; states of data (in transit, at rest, in use); protocols that use encryption

## 2.0 Basic Network Security Concepts
- 2.1 Describe TCP/IP protocol vulnerabilities: TCP, UDP, HTTP, ARP, ICMP, DHCP, DNS
- 2.2 Explain how network addresses impact network security: IPv4/IPv6, MAC addresses, segmentation, CIDR, NAT, public vs private
- 2.3 Describe network infrastructure and technologies: security architecture, DMZ, virtualization, cloud, honeypot, proxy, IDS, IPS
- 2.4 Set up a secure wireless SoHo network: MAC filtering, encryption standards and protocols, SSID
- 2.5 Implement secure access technologies: ACL, firewall, VPN, NAC

## 3.0 Endpoint Security Concepts
- 3.1 Describe operating system security concepts: Windows, macOS, Linux; Windows Defender, host-based firewalls; CLI and PowerShell; file and directory permissions; privilege escalation
- 3.2 Endpoint tools that gather security assessment information: netstat, nslookup, tcpdump
- 3.3 Verify endpoints meet security policies and standards: hardware/software inventory, program deployment, backups, regulatory compliance (PCI DSS, HIPAA, GDPR), BYOD
- 3.4 Implement software and hardware updates: Windows Update, application updates, drivers, firmware, patching
- 3.5 Interpret system logs: Event Viewer, audit logs, system/application logs, syslog, anomalies
- 3.6 Malware removal: scanning, reviewing scan logs, remediation

## 4.0 Vulnerability Assessment and Risk Management
- 4.1 Explain vulnerability management: identification, management, mitigation; active and passive reconnaissance; testing (port scanning, automation)
- 4.2 Threat intelligence techniques: vulnerability databases (uses and limits); industry-standard assessment tools; CVEs, reports, news, subscriptions, collective intelligence; ad hoc and automated threat intel; keeping documentation and communication updated before, during, and after incidents
- 4.3 Explain risk management: vulnerability vs risk; ranking risks; approaches; mitigation strategies; risk levels (low, medium, high, extremely high); data classification; security assessments of IT systems
- 4.4 Disaster recovery and business continuity: natural and human-caused disasters; DRP and BCP features; backup; controls (detective, preventive, corrective)

## 5.0 Incident Handling
- 5.1 Monitor security events and know when to escalate: SIEM and SOAR; monitoring network data (packet captures, logs); identifying suspicious events
- 5.2 Digital forensics and attack attribution: Cyber Kill Chain, MITRE ATT&CK, Diamond Model; TTPs; sources of evidence; evidence handling and chain of custody
- 5.3 Compliance frameworks and incident handling: GDPR, HIPAA, PCI-DSS, FERPA, FISMA; reporting and notification
- 5.4 Elements of incident response: policy, plan, procedure; IR lifecycle (NIST SP 800-61 sections 2.3, 3.1 to 3.4)
